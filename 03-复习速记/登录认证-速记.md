# 登录认证 - 复习速记

## 1. 登录和认证的区别

- 登录：第一次校验用户名和密码
- 认证：后续每次请求证明“我还是那个已登录用户”

一句话：

> 登录解决“你是谁”，认证解决“你之后每次来是不是还是你”。

## 2. 登录功能的主线

```text
前端传账号密码
-> Controller 接参数
-> Service 判断是否登录成功
-> Mapper 查数据库
-> 返回登录结果
```

## 3. 为什么不能只做登录，不做认证

- 用户登录成功一次后，还会继续访问很多接口
- 如果没有认证机制，后端无法识别后续请求是谁发来的
- 这样任何人都可能直接调用受保护接口

## 4. `Session`、`Token`、`JWT`

- `Session`：服务端保存登录状态
- `Token`：客户端后续请求携带令牌
- `JWT`：一种固定格式的 `Token`

速记：

```text
Session：服务端记住你
Token：你自己带凭证
JWT：一种常见 Token 格式
```

## 5. 登录校验到底校验什么

- 有没有登录标识
- 登录标识是否合法
- 登录标识是否过期
- 当前请求是否需要登录后访问

## 6. `Filter` 和 `Interceptor`

- `Filter`：更靠前，属于 Servlet 层
- `Interceptor`：更靠近 Controller，属于 Spring MVC 层

速记：

> `Filter` 更底层，`Interceptor` 更贴近业务接口。

## 7. 登录认证完整闭环

```text
登录成功
-> 生成 Session / Token / JWT
-> 前端保存登录标识
-> 后续请求带回来
-> Filter / Interceptor 统一校验
-> 合法放行，不合法拦截
```

## 8. 今天先记住这 5 句

1. 登录不是认证，认证也不是重新登录
2. 后续请求不再重复传密码，而是带登录标识
3. `Session` 主要是服务端存状态
4. `JWT` 本质上还是 `Token`
5. 登录校验通常做成统一拦截，而不是散落在每个接口里
