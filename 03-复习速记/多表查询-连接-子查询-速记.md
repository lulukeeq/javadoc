# 多表查询 / 连接 / 子查询 - 复习速记

## 1. 什么时候用 `INNER JOIN`，什么时候用 `LEFT JOIN`

- `INNER JOIN`：只保留两张表能匹配上的数据
- `LEFT JOIN`：保留左表全部数据，右表匹配不上时显示 `NULL`
- 记法：谁放在 `LEFT JOIN` 左边，谁就一定保留

案例：

```sql
-- 只查有部门的员工
SELECT e.name, d.name
FROM emp e
INNER JOIN dept d
ON e.dept_id = d.id;

-- 查所有员工，没有部门也显示
SELECT e.name, d.name
FROM emp e
LEFT JOIN dept d
ON e.dept_id = d.id;
```

## 2. 外连接统计数量时怎么写

- 统计右表真实匹配数量时，用 `COUNT(右表主键)`
- 不要盲目用 `COUNT(*)`
- 原因：`LEFT JOIN` 即使匹配不上，左表那一行也会保留；`COUNT(*)` 会把这行也数进去

案例：

```sql
-- 查所有部门的员工人数
SELECT d.name, COUNT(e.id) AS emp_count
FROM dept d
LEFT JOIN emp e
ON d.id = e.dept_id
GROUP BY d.id, d.name;
```

## 3. `WHERE` 和 `HAVING` 的区别

- `WHERE`：分组前筛选普通行数据
- `HAVING`：分组后筛选统计结果
- 例子：`WHERE e.salary > 10000` 是先筛员工；`HAVING COUNT(*) > 10` 是筛分组结果

案例：

```sql
SELECT d.name, COUNT(e.id) AS emp_count
FROM dept d
INNER JOIN emp e
ON d.id = e.dept_id
WHERE e.salary > 10000
GROUP BY d.id, d.name
HAVING COUNT(e.id) > 5;
```

## 4. `GROUP BY` 的记法

- 用了 `GROUP BY` 后，`SELECT` 里通常只能放两类内容：
- 分组字段
- 聚合函数，例如 `COUNT()`、`AVG()`、`MAX()`
- `GROUP BY` 中的字段可以不出现在 `SELECT` 中

案例：

```sql
SELECT d.name, COUNT(e.id)
FROM dept d
INNER JOIN emp e
ON d.id = e.dept_id
GROUP BY d.id, d.name;
```

## 5. `LEFT JOIN` 时右表条件放哪里

- 如果要保留左表全部数据，右表筛选条件优先放 `ON` 中
- 如果把右表条件写到 `WHERE` 中，可能会把左连接打成类似内连接的效果
- 记法：要保留左表，右表条件放 `ON`

案例：

```sql
-- 查所有部门中，工资大于 10000 的员工人数
SELECT d.name, COUNT(e.id)
FROM dept d
LEFT JOIN emp e
ON d.id = e.dept_id
AND e.salary > 10000
GROUP BY d.id, d.name;
```

## 6. 什么时候要 `GROUP BY`

- 如果只是统计总数，用 `COUNT(...)` 就够了
- 如果题目里有“每个部门”“每个分类”“按什么统计”，通常就要 `GROUP BY`

案例：

```sql
-- 统计员工总人数
SELECT COUNT(e.id)
FROM emp e;

-- 统计每个部门员工人数
SELECT d.name, COUNT(e.id)
FROM dept d
LEFT JOIN emp e
ON d.id = e.dept_id
GROUP BY d.id, d.name;
```

## 7. 连接查询和子查询怎么判断

- `JOIN`：先把表关联起来，再筛选
- 子查询：先查一个结果，再拿这个结果去查外层 SQL
- 如果要同时展示多张表字段，通常 `JOIN` 更自然
- 如果题目很适合拆成“先查 A，再查 B”，子查询也很合适

案例：

```sql
-- JOIN 写法：查教研部员工姓名和工资
SELECT e.name, e.salary
FROM emp e
INNER JOIN dept d
ON e.dept_id = d.id
WHERE d.name = '教研部';

-- 子查询写法：先查部门 id，再查员工
SELECT name, salary
FROM emp
WHERE dept_id = (
    SELECT id
    FROM dept
    WHERE name = '教研部'
);
```

## 8. 当前最容易忘的几句

- 要保留左表，用 `LEFT JOIN`
- 外连接统计右表数量，用 `COUNT(右表主键)`
- `WHERE` 筛选分组前，`HAVING` 筛选分组后
- 要按“每个部门”统计，就考虑 `GROUP BY`
- 想保留左表时，右表条件尽量写进 `ON`
