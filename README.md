# javadoc 学习笔记目录

当前目录按“计划、资料、笔记、复习、练习、片段”来分层：

- `00-计划/`：当天计划、学习安排、进度
- `01-原始资料/`：视频配套资料、课件、截图、参考图
- `02-学习笔记/`：按主题整理后的正式笔记
- `03-复习速记/`：短答案、易错点、快速回顾
- `04-练习代码/`：Java demo、SQL 练习、可运行代码
- `05-常用片段/`：常用模板和可复用起手式

使用规则：

1. 原始资料只存档，不直接当正式笔记。
2. 同一个知识点，原则上只保留一篇正式笔记。
3. 复习时优先看 `03-复习速记/`，想不起来再回看 `02-学习笔记/`。
4. 代码和笔记分开，避免文档和 demo 混在一起。
